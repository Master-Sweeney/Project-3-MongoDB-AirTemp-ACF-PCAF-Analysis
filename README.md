This python script was created to practice and demonstrate my ability to access and parse through a NoSQL MongoDB database. 
It was also created with the intention of extract data, observing and exploring its characteristics and then plotting an
AutoCorrelation Function and Partial AutoCorrelation function to determine what kind (if any) relationship exists between
the readings of air temperature in a time series data format. The scipt makes use of the sample_weatherdata set retrieved 
from a MongoDB server, using the pyMongo library.
